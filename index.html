Collega Firebase

Per far vedere gli stessi turni a te e al collega serve un piccolo archivio condiviso gratuito (Firebase). Va fatto una volta sola:

  1. Vai su console.firebase.google.com, crea un progetto (nome libero, es. "Turni").
  2. Nel progetto: Build → Firestore Database → Crea database, scegli "modalità produzione", una qualsiasi regione europea.
  3. Dentro Firestore, tab Regole, incolla:
    allow read, write: if true; dentro match /{document=**} e pubblica.
  4. Impostazioni progetto (ingranaggio) → in basso "Le tue app" → icona </> (Web) → registra l'app → copia l'oggetto firebaseConfig.
  5. Incollalo in cima allo script di index.html, al posto dei valori INCOLLA_QUI.
